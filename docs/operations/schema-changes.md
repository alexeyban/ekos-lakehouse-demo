## Policy

| Change in source | Default action |
|---|---|
| New table | auto: bronze + silver generated |
| New nullable column | auto: Iceberg ADD COLUMN |
| Safe widening (int → bigint, …) | auto: type promotion |
| New NOT NULL column / default | proposal: backfill decision |
| Column rename | proposal: rename, never drop + add |
| Column or table drop | proposal with impact |
| Narrowing / incompatible type | proposal; table paused |
| Key change | proposal; silver dedup paused |
| Watermark trigger changed | proposal |
